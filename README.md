# Mental Map Atlas

An interactive world atlas: take the five-stop **Meet Nigeria again** journey, explore every country, follow eleven geography lessons, and test yourself with map games.

**Live:** https://okunomodammy-pixel.github.io/atlas/

`index.html` is the whole app (data and libraries included), so it also works offline when opened directly. On a phone, use "Add to Home Screen" to install it like an app.

Journeys include short illustrated field notes, map challenges, hints, a personal journal and later review. Notes and progress stay in your browser; no account or paid map service is needed.

Map data: Natural Earth (public domain). Historical boundaries: historical-basemaps (GPL-3.0).

Development direction and agreed resource budgets: [improvement plan](docs/PLAN.md).
