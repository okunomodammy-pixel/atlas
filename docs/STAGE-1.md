# Stage 1: dependable learning foundations

Implemented against main `ec60fc3b8a7fadd1b9d9301844e3b38f642168a8`, following the owner's approved [plan](PLAN.md).

## User-visible behaviour

- Leaving or replacing a location/Nigeria-state quiz cancels its pending advancement, including the final round. Old feedback cannot replace the destination screen.
- Small-screen lessons start with a smaller map and more room to read. More reading / More map buttons work with touch or keyboard, and the original drag handle remains available. Map settings scroll independently and zoom controls stay clear of the Map button.
- Dialogs contain keyboard focus, make the background inert, and restore the original opener on close, including comparison/source/back transitions. New panel content receives heading focus. Quiz explanations have a live status region. Core map flight and zoom animations respect reduced-motion preference.
- The course distinguishes check passes from remembered-later status. A pass still means three correct answers. Remembered later requires every question in that lesson bank to have a correct answer followed by a correct later scheduled review. Further mistakes remove that memory claim while retaining the check pass.
- Extra practice does not advance spaced-review intervals before a question is due or more than once per calendar day. A mistake restarts review from the next day. The latest answer is tracked separately so immediate correction is recognised as practice without overstating delayed recall.
- Failed writes show a persistent warning and a retry action. An unreadable original save is protected from overwrite while the atlas remains usable.

## Existing progress

The `mma.v1` storage key remains in use. The stored object receives `schemaVersion: 2` and a `checks` dictionary migrated from the old `mastered` dictionary. Existing seen places, best scores, lesson visits, theme, question records/due dates and unknown fields are preserved. The old `mastered` field remains historical data. Old review boxes alone do not count as evidence for the new memory label.

If a save cannot be read, the app warns and leaves that original entry untouched. It does not attempt to merge unknown old data with a new session. Profile export/import and multiple explorers remain Stage 3 work.
